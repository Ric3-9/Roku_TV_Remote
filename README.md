This program is made entirely in Java and is meant to be operated through a command line. 
This is made specifically for Roku TVs and there is no guarantee it will work on different models nor newer versions.
This is a project solely made by Ric3-9 or my other GitHub TrueJayfeath3r.

To run the code as intended, turn on the TV and make sure your computer and TV are on the same network.
The code requires the ability to scan your network to automatically find a TV.
If you have multiple TVs on the same network you may have to input the IP address manually to prevent connecting to the wrong TV.
